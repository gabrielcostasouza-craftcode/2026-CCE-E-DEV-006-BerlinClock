
# Used to generate scaffold: 

- React: npm create vite@latest frontend -- --template react-ts
- Spring Boot + Web dep: https://start.spring.io/


# Run:

## backend:
    - in: com.gabriel.berlinclock, run file BerlinclockApplication.java through your IDE
## frontend: 
    - open terminal on frontend folder
    - npm ci
    - run: 'npm run dev' in terminal
    - access: http://localhost:5173/
    - Time example: 22:53:33
    - Berlin example: YRRROROOOYYRYYRYYRYOOOOO
    Tests:  - run: 'npm run test' in terminal
